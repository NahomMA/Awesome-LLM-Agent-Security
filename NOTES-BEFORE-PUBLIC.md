# Before making this repository public — checklist

(Delete this file when going public.)

1. **Venue anonymity.** If the companion paper is under review at a double-blind venue
   (e.g. IEEE S&P / USENIX SoK), a public repo linkable to the paper can break anonymity —
   keep private until decision, or strip the "companion paper" note. Single-blind venues
   (JAIR, ACM CSUR) are fine.
2. **Co-author sign-off** on going public and on the repo name/branding.
3. Rename the GitHub repo to `Awesome-LLM-Agent-Security` (Settings → General → Rename);
   old remote URLs redirect automatically.
4. After the paper is accepted: update CITATION.cff and the README placeholder with the
   real citation; consider a Zenodo archive for a DOI (adoption evidence).
5. Optional discoverability: repo topics (`llm-agents`, `ai-security`, `prompt-injection`,
   `awesome-list`, `llm-security`), a social-preview image, and a submission to
   sindresorhus/awesome once the list is public and stable.
